### Fast Forward
To automatically apply all the changes necessary for OTel instrumentation simply run the fastforward.sh script with the repo name as the only argument
```bash
./fastforward.sh {your-repo-name-as-it-appears-in-the-env-file}
```
### Reset
If you then want to remove all the OTel stuff, simply run the reset.sh script

```bash
./reset.sh {your-repo-name-as-it-appears-in-the-env-file}
```
Enjoy
